# unity-PerfectHEX

탑뷰 턴제 전략 RPG입니다(2021.12 ~ 2022.02, 1인). 게임 내의 모든 오브젝트와 상호작용할 수 있도록 하는 것이 목표였습니다.

- 기술 Unity, C#

## 구현

- 3D 타일맵 배치 시스템
- 적 및 플레이어 오브젝트의 턴제 시스템
- 상속 기반 구조로 모든 오브젝트와 상호작용 가능

## 링크

- 프로젝트 상세 (Notion): [PerfectHex](https://military-guanaco-a36.notion.site/353a22a554398049be64cf358ed423b7)
